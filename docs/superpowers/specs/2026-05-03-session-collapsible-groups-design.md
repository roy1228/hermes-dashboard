# 会话列表折叠分组 — 设计文档

## 概述

在 Hermes Dashboard 的会话管理面板中，为左侧会话列表添加按时间分组的折叠功能，提升大量历史对话的可浏览性。

## 分组定义

| 分组名 | 时间范围 | 默认状态 | 排序 |
|--------|---------|---------|------|
| 今天（24h 内） | `0 ~ 24h` | 展开 | 1 |
| 3 天内 | `24h ~ 72h` | 展开 | 2 |
| 3-7 天 | `72h ~ 168h` | 收起 | 3 |
| 7 天-1 个月 | `168h ~ 720h` | 收起 | 4 |
| 1 个月以上 | `> 720h` | 收起 | 5 |
| 未知时间 | 无法解析 | 收起 | 6 |

## 时间解析

从 `hermes sessions list` 输出的 `ago` 字段解析小时数：

- `just now` → 0 小时
- `Xm ago` → 0 小时（不足 1 小时归入今天）
- `Xh ago` → X 小时
- `Xd ago` → X × 24 小时
- 无法解析 → 归入"未知时间"分组

## 交互行为

### 分组展开/收起
- 点击分组行或按 Enter → 切换展开/收起
- 展开图标：`▾`（展开）/ `▸`（收起）
- 分组行显示计数：`▾ 今天（24h 内）（3 个对话）`
- 空分组仍显示，标注 `0 个对话`

### 搜索行为
- 搜索模式下隐藏所有分组行，平铺显示所有匹配项
- 清空搜索框 → 恢复分组视图
- 搜索不改变分组的展开/收起状态

### 其他操作
- 新会话/删除/重命名后刷新列表时，重新计算分组归属
- 选中会话加载聊天不受分组状态影响

## 技术实现

### 方案：DataTable 行分组

在现有 `DataTable` 中插入分组标题行作为特殊标记行，通过 `key` 前缀区分分组行和数据行。

### 新增数据结构

```python
@dataclass
class SessionGroup:
    name: str           # 显示名，如 "今天（24h 内）"
    key: str            # 唯一标识，如 "__group:today__"
    expanded: bool      # 默认展开状态
    order: int          # 排序优先级
```

### SessionsPane 新增状态

| 属性 | 类型 | 说明 |
|------|------|------|
| `_groups` | `list[SessionGroup]` | 分组定义列表 |
| `_collapsed_groups` | `set[str]` | 当前收起的分组 key 集合 |
| `_search_mode` | `bool` | 是否处于搜索覆盖模式 |

### 方法变更

| 方法 | 变更内容 |
|------|---------|
| `_fetch_sessions` | 解析 `ago` → 分组 → 先插入分组行再插入数据行，根据 `_collapsed_groups` 决定数据行可见性 |
| `_search_sessions` | 搜索模式下不插入分组行，平铺显示所有匹配项 |
| `on_data_table_row_selected` | 判断行 key 是否为分组行前缀，是则切换展开/收起而非加载聊天 |
| `load_sessions` | 保持 `_collapsed_groups` 状态，只刷新数据 |

### CSS 变更

分组行样式通过 Textual 的 row label 或自定义渲染实现：
- 不同背景色（比数据行更深）
- 加粗文字
- 光标样式区分（hover 时显示可点击）

## 错误处理

- `ago` 解析失败 → 归入"未知时间"分组
- 分组行误触发聊天加载 → 通过 key 前缀判断拦截
- 搜索结果为空 → 显示"无匹配结果"提示

## 测试要点

- 时间解析覆盖：`just now`, `30m ago`, `5h ago`, `2d ago`, `15d ago`, `45d ago`
- 分组展开/收起状态在刷新后保持
- 搜索模式切换正确
- 空分组显示正常
- 删除会话后分组计数更新
