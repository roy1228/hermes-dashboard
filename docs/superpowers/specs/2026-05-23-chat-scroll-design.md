# 聊天区域滚动条和自动滚动设计文档

## 概述

修复会话聊天区域的两个体验问题：
1. 当前隐藏了垂直滚动条（`scrollbar-size: 0 0`），用户无法拖动滚动条浏览历史
2. 打开会话、收到新消息时不会自动滚动到最新消息位置

## 需求

- 聊天区域显示可拖动的垂直滚动条
- 打开会话时自动滚动到最新一条消息
- 收到新回答时自动滚动到最新回答
- 流式输出过程中持续跟随底部

## 改动

### 1. 显示滚动条

**文件：** `hermes_dashboard.py`，`DEFAULT_CSS` 中 `#sess-chat-feed` 规则

将：
```css
scrollbar-size: 0 0;
```
改为：
```css
scrollbar-size: 1 0;
```

`1` 启用垂直滚动条，`0` 不启用水平滚动条。

### 2. 自动滚动到底部

在以下 4 个方法中，设置 `cursor_position` 后调用 `log.scroll_end()`：

| 方法 | 行位置 | 触发场景 |
|------|--------|----------|
| `_add_chat_message` | ~line 302 | 新消息到达 |
| `_start_streaming_ai_message` | ~line 310 | 开始流式输出 |
| `_append_to_streaming_message` | ~line 319 | 流式 chunk 到达 |
| `_load_session_chat` | ~line 606 | 加载完历史消息后 |

`scroll_end()` 是 Textual `TextArea` 的内置方法，将视图滚动到内容末尾。

## 行为说明

- **打开会话**：加载历史 → 自动滚到底部（最新一条）
- **新消息到达**：每次追加消息后滚到底
- **流式输出**：每个 chunk 追加后滚到底
- **用户手动向上滚动**：新消息到达时仍然会强制滚到底部（简单策略，后续可按需增加"跟随模式"开关）

## 测试

手动验证：
1. 打开一个有多条历史的会话 → 确认滚动条可见且自动滚到底部
2. 发送一条消息 → 确认回答过程中持续跟随底部
3. 用鼠标拖动滚动条向上 → 确认可以浏览历史
4. 切换到新会话 → 确认无报错
